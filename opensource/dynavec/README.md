# dynavec landing site

A clean, dependency-free static site for the dynavec open-source project.
Black-and-white, minimalist, no build step, no trackers, no external JS —
just HTML, CSS, and a small vanilla `script.js`.

## Files

```
opensource/dynavec/
├── index.html        # the page (hero, why, architecture, benchmarks, docs, contribute)
├── styles.css        # monochrome design system
├── script.js         # sticky nav, copy buttons, doc tabs, live star count, code highlighter
└── images/           # benchmark charts (generated by `python -m benchmarks.report`)
```

## Run locally

```bash
cd opensource/dynavec
python3 -m http.server 8777
# open http://localhost:8777
```

(Open over HTTP, not `file://`, so the stylesheet, script, and images load.)

## Deploy to GitHub Pages

Option A — publish this folder as the site:

1. Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**, or
2. push the contents of `opensource/dynavec/` to a `gh-pages` branch root, or
3. set Pages to serve from `/docs` and copy this folder there.

The only external request the page makes is to the GitHub API for the live star
count (degrades gracefully offline) and Google Fonts for Inter / JetBrains Mono.

## Refresh the benchmark images

```bash
python -m benchmarks.report --out opensource/dynavec/images
```

## Notes

- Cost figures shown are cost-model estimates from public list prices.
- Recall/latency figures are representative until a live AWS benchmark run.
