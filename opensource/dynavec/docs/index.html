    dynavec / Docs

    The agent stack in your AWS account

    Open-source, serverless memory, orchestration, observability and evaluation — one Python library.

    dynavec starts as a hybrid vector database that fuses Amazon DynamoDB (single-digit-millisecond document store) with Amazon S3 Vectors (billion-scale serverless ANN), and grows into agents, traces and evals. Everything runs in your AWS account and bills only when you use it — no external control plane.
